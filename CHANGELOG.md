# Changelog

## 1.0.0 - 2026-11-21

- Laravel 12 and Laravel 13 support with PHP 8.2+ (Laravel 13 requires PHP 8.3+).
- Access to all 23 requests documented in Voipano Public API v1 (2026.11.21).
- Service/token scoping, per-request correlation IDs, and typed HTTP exceptions.
- Contact management, voice calls, reporting, recording downloads, and webhook configuration.
- Optional, disabled-by-default webhook receiver with a configurable verifier.
- PHPUnit tests and GitHub Actions compatibility matrix.
